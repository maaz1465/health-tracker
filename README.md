# 🏃 PulseFit - Health, Fitness & Nutrition Tracker

A comprehensive, modern, and interactive Health, Fitness, and Nutrition Tracking web application.

---

## ✨ Features

- 📊 **Interactive Dashboard**: Real-time metrics for steps, calories, water intake, workouts, and sleep.
- ⚖️ **Smart BMI Calculator**: Instant BMI calculation with health category breakdown and tailored recommendations.
- 💧 **Hydration Tracker**: Log daily water intake with visual progress and reminder intervals.
- 🥗 **Nutrition & Macro Tracker**: Track calories, protein, carbs, and fats with meal breakdowns.
- 🏋️ **Workout & Activity Log**: Record workout sessions, duration, intensity, and calories burned.
- 📈 **Visual Analytics**: Dynamic charts and progress indicators for long-term health trends.
- 🌙 **Modern Glassmorphic UI**: Sleek dark-mode aesthetic with fluid micro-interactions and responsive design.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher recommended)
- A modern web browser

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/maaz1465/health-tracker.git
   cd health-tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   # or
   npm start
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000` to view the app.

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3
- **Dev Server**: `serve`
- **Design System**: Responsive glassmorphism, CSS Custom Properties, SVG Icons
